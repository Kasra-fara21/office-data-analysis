# office-data-analysis
Data cleaning and analysis of office employee data using Python and Pandas.
## Features

- Handle missing values (NaN)
- Remove duplicate records
- Filter unrealistic ages
- Analyze salaries
- Analyze employee data by department
- Find the highest-paid employee
- Calculate total and average salaries
- Analyze employee distribution by city
- Calculate average work experience

## Technologies

- Python
- Pandas

## How to Run

1. Make sure Python and Pandas are installed.
2. Keep `employee.py` and `emp.csv` in the same directory.
3. Run the program:

```bash
python employee.py
